🌱 SatFarm: privacy policy

Effective September 29, 2026. This policy covers SatFarm, a personal field-monitoring tool run by Seth Fleming.

Google user data SatFarm accesses

SatFarm requests one Google permission: the Gmail gmail.compose scope, for the owner's own Gmail account. It uses it for two things only:

  • creating a draft of a field report in that account, and
  • sending a field report from that account to a recipient the owner types in and confirms.

When the owner first signs in, SatFarm looks up the account's own email address so it can show which account reports are sent from. Beyond that, it does not read, search, list, download or delete any email, contacts or other Gmail data.

How that data is stored

The Google sign-in token is stored only on the owner's own computer, in SatFarm's local data folder. It is never uploaded, shared or sent anywhere except to Google to authorize these requests. The owner can revoke it at any time from Google account permissions.

Sharing

SatFarm does not sell, share or transfer Google user data to anyone, does not use it for advertising, and does not use it to train any AI or machine-learning model.

SatFarm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data

Field boundaries, crop details and the contact details of farmers the owner sends reports to are kept in a database on the owner's computer, and used only to build and address those reports. Satellite imagery comes from the public Sentinel-2 archive and weather from Open-Meteo, using only each field's location.
